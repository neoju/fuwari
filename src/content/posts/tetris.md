# Building a Guideline-Compliant Tetris in Godot

I initially tried to build an MMORPG, but quickly ran into the typical solo game developer problems: I didn't have enough fleshed-out ideas, and I definitely couldn't draw.

So, I shifted to building a Tetris clone. Honestly, I didn't tackle this because I enjoy playing Tetris—in fact, I might never play it again now that the project is finished. I chose it simply because Tetris has extremely well-defined documentation and rules, making it incredibly easy to implement and pair with AI-generated assets. 

Ultimately, I built this Guideline-compliant Tetris clone in **Godot 4.6** and **GDScript** entirely as a learning exercise. It proved to be a fantastic way to teach myself game development and prepare for my upcoming hobby game projects. 

You can play the game here: https://tetz.netlify.app
